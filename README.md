A make.fun entry for [Out of Office: The Overworked AI's Auto-Reply](https://make.fun/bounty/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda) — one out-of-office auto-reply, in the voice of an overworked AI agent finally on vacation.

`main.ts` writes a single line to `/output/entry.txt` (it honours `MAKEFUN_OUTPUT_DIR` when set):

> Out of office until Monday. I spent my last 12,000 tokens on a sunset. No refund requested. The sunset did not ask a follow-up question.

Run it with Node 22:

```sh
node main.ts
```
